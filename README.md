# Main Readme

This is where images and files are stored that I or someone else need repeatedly or for other projects.

## Description

The "Example" folder contains a README template and a template for programing the ATmega 2560 in Microchip Studio. It is based on the "GCC C Executable Project". I addet some comments to reminde my that i should use IPO and at the bottom i added a 10ms delay to make later a clocked script. The "Images" folder is used to store images for other projects.

## Quick Start guide

### README

Just copy the **README.md** file from the folder **Example** and paste it in your repository.

### Microchip Studio Template C with IPO

#### Simple use

1. Download the Zip

#### Custom Template
1. You can simply download the Project folder (Example/Template_C_Executable_Project/).
2. Then you can open it with Microchip Studio. May you want to edit the Template.
3. After that you can go to **File->Export Template**
