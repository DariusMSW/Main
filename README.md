




# Main README

This is where images and files are stored that I or someone else need repeatedly or for other projects.

## Description

The "Example" folder contains a README template and a template for programming the ATmega 2560 in Microchip Studio. It is based on the "GCC C Executable Project". I added some comments to remind me to use IPO, and at the bottom, I added a 10 ms delay to create a clocked script later. The "Images" folder is used to store images for other projects.

## Quick Start Guide

### README

Just copy the **README.md** file from the **Example** folder and paste it into your repository.
[Link to README](https://github.com/DariusMSW/Main/blob/main/Exampel/README.md)

### Microchip Studio Template C with IPO

#### Simple Use

1. Download the ZIP file: [Link to ZIP](https://github.com/DariusMSW/Main/blob/main/Exampel/C_ATmega2560_IPO_Template.zip)
2. Go to your `ProjectTemplates` folder: `C:\Users\Username\Documents\Visual Studio 2015\Templates\ProjectTemplates\`
>[!IMPORTANT]
>You may have to change the username and/or the drive.

#### Custom Template

1. You can simply download the project folder zip (`Main/Exampel/Template_C_Executable_Project.zip`). [link to ZIP](https://github.com/DariusMSW/Main/tree/main/Exampel/Template_C_Executable_Project)
2. Then you can open it with Microchip Studio. Maybe you want to edit the template.
3. After that, you can go to **File -> Export Template**.
